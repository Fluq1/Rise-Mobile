# Rise-Mobile

![Logo do Projeto](./assets/logo.webp)

Projeto desenvolvido como trabalho acadêmico para a faculdade. **Este código é estritamente para fins educacionais e não pode ser utilizado comercialmente.**

---

## ✨ Sobre o Projeto

O **Rise-Mobile** é um aplicativo mobile de e-commerce de moda, desenvolvido em React Native com Expo, que permite ao usuário realizar cadastro, login, visualizar produtos, categorias e novidades, além de utilizar autenticação via Firebase.

---

## 🚀 Tecnologias Utilizadas

- **React Native**: Framework principal para desenvolvimento mobile.
- **Expo**: Ferramenta para facilitar o desenvolvimento e testes.
- **Firebase**: Autenticação de usuários (cadastro, login, reset de senha).
- **React Navigation**: Navegação entre telas.
- **React Native Gesture Handler**: Melhor experiência de gestos.
- **Expo Linear Gradient**: Gradientes visuais.
- **React Native Paper**: Componentes visuais modernos.
- **React Native Vector Icons**: Ícones vetoriais.
- **Validações customizadas**: CPF, telefone, CEP e senha.
- **Animações**: SplashScreen animada e transições suaves.

---

## 📱 Funcionalidades

- Tela de Splash animada
- Cadastro de usuário com validação de CPF, telefone, CEP e senha forte
- Login com autenticação Firebase
- Recuperação de senha via email
- Listagem de produtos, categorias e novidades
- Interface moderna e responsiva
- Componentes customizados reutilizáveis
- Temas e estilos centralizados

---

## 🛠️ Como rodar o projeto

1. **Pré-requisitos**:
   - Node.js e npm/yarn instalados
   - Expo CLI (`npm install -g expo-cli`)

2. **Instale as dependências**:
   npm install

3. **Inicie o projeto**:
npm start
expo start

4. **Abra no seu dispositivo**:
Use o app Expo Go no seu celular para escanear o QR Code.
